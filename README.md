# website-vizia

Landing page one-pager pour [Vizia](https://github.com/vizia/vizia), une bibliothèque GUI déclarative pour Rust.

Construite avec [Vue 3](https://vuejs.org/) + [Vite](https://vite.dev/) + TypeScript.

## Développement

```bash
npm install
npm run dev       # serveur de dev
npm run build     # typecheck + build de production dans dist/
npm run preview   # prévisualiser le build
```

## Contenu

- Hero avec stats GitHub (étoiles, contributeurs, forks, version)
- Capture d'écran de la widget gallery
- Grille de fonctionnalités
- Exemple de code (counter)
- Showcase communautaire (audia, sample browser, plugins audio)
- CTA : livre, GitHub, Discord, `cargo add vizia`

Les stats et liens sont à jour au 18 août 2026 (GitHub API). Les captures du showcase sont hotlinkées depuis les repos GitHub du projet.
